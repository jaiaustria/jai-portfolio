FREE PUBLISHING WITH GITHUB PAGES
1. Sign in or create a GitHub account.
2. Create a PUBLIC repository named jai-portfolio.
3. Upload index.html, jo-profile.png, and all three portfolio PNG files to the repository root.
4. Open Settings -> Pages.
5. Under Build and deployment, choose "Deploy from a branch", select "main" and "/ (root)", then Save.
6. The Pages section will show the live website URL after deployment. It will look like https://YOUR-USERNAME.github.io/jai-portfolio/

A GitHub Pages website is public. Do not upload private personal information.
